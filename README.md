# MyAssistant — Human Chat
Premium ChatGPT-style Android chat assistant.
- Natural Hindi/Hinglish/English conversation
- Persistent chats and memory
- New Chat
- Sidebar history
- Long press chat: Rename/Delete
- Coding help and code explanations
- Optional foreground voice input/output only when the user taps the microphone
- No phone/app control, no accessibility control, no background wake word
